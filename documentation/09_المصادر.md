# مصادر ومراجع

## مصادر البحث اونلاين

### Airdrop Bots
1. **[Crypto-Airdrop-Farming-Bot](https://github.com/Crypto-Airdrop-Farming-Bot)**
   - وصف: بوت أوتوماتيكي ل Airdrop Farming على EVM و Solana
   - ميزات: multi-wallet, proxy rotation, modular campaigns
   - لغة: Python

2. **[Solana Airdrop Bot](https://github.com/airpowersa/airdrop)**
   - وصف: بوت اكتشاف Airdrops على Solana
   - ميزات: AI-based discovery, auto-notification
   - لغة: Python

3. **[CosmicStar](https://github.com/Aarlez/CosmicStar)**
   - وصف: بوت Airdrop على Solana
   - ميزات: Auto-claim, premium APIs, Chromedriver
   - لغة: Python

4. **[AirDrop-Checker](https://github.com/AirDrop-Checker)**
   - وصف: أداة للتحقق من أهلية Airdrops
   - ميزات: Scam detection, SPL token/NFT rewards
   - لغة: Multiple

   - ميزات: Tools, protocols, repos

### DEX Aggregators

2. **[1inch](https://1inch.io/)**

5. **[Autobahn](https://github.com/blockworks-foundation/autobahn)**
